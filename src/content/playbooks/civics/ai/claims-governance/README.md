# AI Claims Governance

This package is for the institutional side of claims and eligibility systems: action thresholds, ownership, procurement terms, auditability, and the minimum floor for adverse decisions in low-exit systems.

Use it when the question is what agencies, payers, buyers, oversight bodies, or advocates should require before AI-assisted denial systems are treated as legitimate.
