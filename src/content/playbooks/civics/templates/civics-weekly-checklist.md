# Civics Weekly Checklist

## This week

- [ ] One ask drafted or sent
- [ ] One channel used
- [ ] One follow-up date set
- [ ] One log entry completed

## If it is election season

- [ ] voter list updated
- [ ] next 30-day, 7-day, or 1-day check identified

## If it is budget or hearing season

- [ ] next decision date identified
- [ ] target map updated
- [ ] testimony or comment draft ready

## If it is a watchdog week

- [ ] contract, budget, or dashboard checked
- [ ] escalation channel identified if needed
