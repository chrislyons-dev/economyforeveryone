# AI Workplace Governance

This package is for the broader workplace rules around AI systems that affect jobs, pay, scheduling, discipline, promotion, evaluation, monitoring, or hiring.

Use it when the problem is bigger than ladder health and the real question is whether a consequential workplace AI system can be governed, challenged, audited, and paused.

## Use this package for

- procurement and vendor review
- HR policy and internal rules
- notice, reason, appeal, records, and override floors
- auditability and decision ownership
- workplace AI systems broader than the career-ladder problem
