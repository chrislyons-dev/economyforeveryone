# Workplace Playbooks

This lane is for the rules and routines that shape daily work.

Focus:

- hiring
- scheduling
- evaluation
- discipline
- monitoring
- grievance and appeal paths
- worker-facing guardrails

This is distinct from:

- `civics`: public leverage, procurement pressure, regulators, legislation, and oversight
- `community`: local implementation in schools, cities, counties, and neighborhood institutions

## Start here

- [Workplace Issue Map](./workplace-issue-map.md)

Start there when something at work feels off but the real failure mode is still fuzzy.
It helps name whether the problem is capacity, metrics, admin drag, accountability, training, or incentives.
