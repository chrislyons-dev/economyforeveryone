# Workplace Playbooks

This lane is for internal institutional rules that shape daily work.

Focus:

- hiring
- scheduling
- evaluation
- discipline
- monitoring
- grievance and appeal paths
- worker-facing guardrails

This is distinct from:

- `civics`: public leverage, procurement pressure, regulators, legislation, and oversight
- `community`: local implementation in schools, cities, counties, and neighborhood institutions

## Start here

- [Workplace Issue Map](./workplace-issue-map.md)

Use that first when you need to name the failure mode before deciding whether the problem is capacity, metrics, admin drag, accountability, training, or incentives.
