# Community Modules (Topic Menus)

These modules are _not_ essays.
They are menus of measurable asks you can use in meetings, emails, and one-pagers.

## How to use a module

1. Pick **one** squeeze lane
2. Pick **one** bottleneck you can name in one sentence
3. Pick **one ask** (who / what / when / metric)
4. Add 3-5 scoreboard metrics
5. Show up and follow up once

## Module Sprint (60 minutes)

1. Pick one lane and one bottleneck
2. Build a target map
3. Write the ask memo
4. Draft the 90-second testimony
5. Build the scoreboard stub
6. Send two messages
7. Schedule follow-up and log it

Use the [module sprint kit](../templates/module-sprint-kit.md).

## Keep modules small

If you add more than ~12 quick wins, you are building a catalog, not a tool.
If you need more, create a **receipts stub** or a **case study** link instead.

## Definition of done

You are done with a module session when you can name:

1. one bottleneck
2. one ask
3. one owner
4. one metric
5. one target map
6. one follow-up date
7. one public-record step if ignored
