These modules are _not_ essays.
They are menus of measurable asks you can use in meetings, emails, and one-pagers.

## How to use a module

1. Pick **one** squeeze lane.
2. Pick **one** bottleneck you can name in one sentence.
3. Pick **one ask** (who / what / when / metric).
4. Add 3-5 scoreboard metrics.
5. Show up and follow up once.

## Keep modules small

If you add more than ~12 quick wins, you are building a catalog, not a tool.
If you need more, create a **receipts stub** or a **case study** link instead.
