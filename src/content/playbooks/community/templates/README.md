## Definition of done

Use these templates to leave each session with:

1. one ask
2. one channel
3. one follow-up date
4. one record of what happened

## Default workflow

1. Pick a bottleneck.
2. Write a one-pager with one ask and one metric.
3. Send the one-ask email or make the call.
4. Show up, testify, or submit comment.
5. Follow up once.
6. Log it and update the scoreboard.
