These templates are “glue.” They turn good intentions into repeatable action.

Keep them short.
Copy/paste freely.
One ask beats ten hot takes.

## Default workflow

1. Pick a bottleneck
2. Write a one-pager (one ask + metric)
3. Send the one-ask email (or call)
4. Show up / testify / submit comment
5. Follow up once
6. Log it and update the scoreboard
