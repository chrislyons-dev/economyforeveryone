# Module Sprint Kit

Use this when you want to turn one module into one real sprint in about 60 minutes.

## The 60-minute sprint

1. Pick one lane and one bottleneck.
2. Build a target map with one staff owner and one elected or public target.
3. Write a 250-400 word ask memo.
4. Draft a 90-second testimony version.
5. Build a scoreboard stub with 3-5 metrics and a data source.
6. Send two messages.
7. Schedule the follow-up and log it.
