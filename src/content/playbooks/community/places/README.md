# Places (E4E)

A “place file” is the wrapper that turns analysis into action.

Each place file should fit on **one screen** and answer:
- who decides
- what’s the bottleneck
- what’s the one ask (measurable)
- what we’re tracking (scoreboard)
- when the next decision happens

Belief tests can live here briefly, but the full detail can be a separate doc.

## Definition of done

A place file is usable when it has:

1. one current squeeze target
2. one bottleneck hypothesis
3. one ask
4. one next decision date
