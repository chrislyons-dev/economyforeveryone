# MD Feedback Questions

Use these to get concrete feedback from a physician quickly.

1. Which 2 workflow categories eat you alive weekly?
2. Which of these are clinic-controlled versus system-controlled?
3. Which one would you actually try next Tuesday?
4. Where would this accidentally increase risk?
5. What do staff do today as the workaround?
6. Where is the handoff fuzzy instead of the work being inherently hard?
7. Which metric would you trust enough to know it actually helped?
8. What would make this worse for harder patients or more complex cases?
9. Which standard play feels safest to try first?
10. What would need leadership, IT, privacy, or payer approval before this could ship?
