# One Ask (Clinic Ops / IT / Leadership)

Use this when you need permission, a report, staffing, or an EHR/workflow change.

Attach one field-note receipt when possible.

**Subject:** Request: **[deliverable]** to reduce **[drag]** (**[metric]** by **[date]**)

## The 6-sentence ask

Hello **[Name/Team]**,

1. I’m seeing **[specific admin drag]** causing **[impact]**.
2. The bottleneck appears to be **[constraint: rule, staffing, EHR friction, payer loop]**.
3. My request: **[one specific action]** by **[date]**.
4. Deliverable: **[report / routing rule / template / EHR change / pilot]**.
5. Dependencies: **[compliance / security / payer / vendor / IT build / none]**.
6. Success looks like: **[metric]** improving by **[target]** within **[time]**.
7. Safety guardrail: **[what will not be automated / how humans stay accountable]**.
8. Who should own the next step, and when can we confirm it?
9. If that is not feasible this cycle, what is the smallest step we can do now (baseline report, pilot with one provider, routing rule) and by when?

Thank you,  
**[Name]**
