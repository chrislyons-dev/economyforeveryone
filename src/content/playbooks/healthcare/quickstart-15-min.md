# Quickstart (15 Minutes)

Use this when you want fast physician feedback without turning it into a project.

## In 15 minutes

1. Pick one category from the [admin drag map](./admin-drag-map.md).
2. Write one [field note](./templates/field-notes.md).
3. Score 2-3 candidate fixes using [triage and prioritization](./triage-and-prioritization.md).
4. Pick one [standard play](./standard-plays.md).
5. Draft one [one ask](./templates/one-ask.md) if the change needs permission or resources.

## Best first categories

- inbox
- prior auth
- referrals
- duplicate entry
- routine refill routing

## Output

At the end of 15 minutes, you should have:

- one named drag point
- one scored target
- one safe next move
