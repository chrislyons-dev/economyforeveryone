# Action Menu (so every post ends with something real)

Pick **one**. Small counts. Consistency beats intensity.

## 1-minute actions

- Don't share the claim yet; ask for a source
- Mute or unfollow one account that reliably inflames you
- Send one calm DM: "You okay?"
- Write your one question (not ten)

## 10-minute actions

- Check one primary source (official site, agenda packet, full clip)
- Send one "One Ask" email to the actual decider
- Make a voting plan (you + one friend)
- Add a receipts stub instead of guessing

## 1-week actions

- Attend or watch one local meeting and log one ask
- Join or start a 3-8 person micro-team (GOTV / policy)
- Submit one public comment on a proposed rule
- Make one recurring donation to a high-execution org (with reporting)

## "If you're mad" actions (heat -> useful)

- Save draft; sleep; reread tomorrow
- Rewrite as: mechanism + uncertainty + ask
- Use a boundary line and step out of comments

## "If you're sad" actions (grief -> care)

- Send one kind message
- Do one practical help
- Log one next step and stop scrolling
