# Channel Shapes

Use the same core rules everywhere.
Change the shape to fit the channel.

## Facebook

- 150-400 words
- 1-2 paragraph breaks
- 1 link max
- end with one ask
- do not argue in circles in comments

## Substack note

- one point
- punchier opening
- more personal voice is fine
- 1 link max
- close quickly

## Substack post

- usually Frame A or Frame G
- include what good looks like
- include related reading
- more room for personal framing than the site

## Blog / site

- more evergreen
- more structured headings
- more receipts
- fewer "I" statements unless they add real value

## Notes / internal drafts

- rough is fine
- mark unknowns plainly
- use receipts stubs instead of pretending certainty
